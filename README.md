# SecPRED
This work focuses on predicting protein secondary structures using machine learning, a key area in bioinformatics with significant applications in medical research and the pharmaceutical industry. Protein secondary structures, including alpha-helices, beta-sheets, and loops, are crucial for understanding their functions and interactions. A combination of convolutional neural networks (CNN) and recurrent neural networks (RNN) has been proposed as an effective method to improve prediction accuracy.
The study achieved significant progress compared to traditional methods. The hybrid CNN-RNN model reached up to 81% accuracy in predicting eight-class secondary structures (Q8) on the CB513 test dataset, representing a 7% improvement over pure CNN approaches. This approach effectively captures spatial and sequential patterns in protein sequences while maintaining low computational complexity.
The project also included the development of a web application that enables users to easily utilize the trained models for protein secondary structure prediction. The application features:
Intuitive user interface
REST API for integration with other bioinformatics tools
Interactive visualization of results
Validation on standardized datasets demonstrated the models' robustness across diverse protein types.
In conclusion, the work highlights the potential of CNN-RNN combinations for advancing protein secondary structure prediction and opens new avenues for future research, including:
Integration of additional biological parameters
Model optimization for specific protein types
Improved interpretability of neural network decision processes
This project contributes to progress in structural bioinformatics and provides a valuable tool for the scientific community.
